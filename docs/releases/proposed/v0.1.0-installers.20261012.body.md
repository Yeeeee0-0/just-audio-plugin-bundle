## 安装与卸载 / Install and uninstall

先保存工程，并关闭正在使用 JUST 的宿主。Windows 装到 x64 VST3 目录，卸载请用这次安装生成的卸载器。macOS 装到 `~/Library/Audio/Plug-Ins/VST3`，卸载时只移除对应的 JUST 插件。
Save your projects and close hosts that use JUST. Windows installs to the x64 VST3 folder; uninstall with the uninstaller from that installation. macOS installs to `~/Library/Audio/Plug-Ins/VST3`; remove only the JUST bundles when uninstalling.
