## 本次更新 / What's new

**修复 / Fixed**
- 没有勾选的第三方链接目录不会再挡住安装。安装器不会进入或修改这些目录；如果选中的 JUST 插件本身是链接，仍然会拒绝安装。<br>Unselected third-party linked directories no longer block installation, and the installer does not enter or modify them. A selected JUST bundle that is itself a link is still refused.
- 宿主保持运行时也能安装和撤销，前提是插件文件能安全移动。安装器会先保留旧版本，再换入新版本。<br>Installation and undo now work while a host is running, as long as the plugin files can be moved safely. The old bundles are kept until the new ones are in place.

**未改动 / Unchanged**
- 十个插件 DLL、界面、DSP、参数和美术均未改动，现有工程直接打开即可。<br>All ten plugin DLLs, UI, DSP, parameters and artwork are unchanged. Existing projects open as before.
- macOS 安装包就是原来那个文件，没有重新构建。<br>The macOS package is the original file and was not rebuilt.

## 安装提示 / Install notes

1. 先保存工程。宿主可以不关。<br>Save your project. The host can stay open.
2. 如果某个插件的编辑窗口锁住了文件，安装器会安全地拒绝安装，原有内容不受影响。关掉那个插件窗口，再重试一次。<br>If an open plugin editor locks the files, the installer safely refuses and leaves the existing files untouched. Close that editor and retry.
3. 装完后，重新打开宿主或重新加载插件，才会用上新版本。不保证所有 DAW 都支持热替换，也不保证切换过程中音频不中断。<br>After installing, reopen the host or reload the plugin to use the new copy. Hot swapping and gap-free audio are not guaranteed in every DAW.
4. 请保留安装报告和备份。如需撤销，运行这次安装对应的 `JUST-uninstall.exe`。<br>Keep the install report and backup. To undo, run the `JUST-uninstall.exe` from that same installation.

详细步骤见 [Windows 安装与撤销](https://github.com/Yeeeee0-0/just-audio-plugin-bundle/blob/main/docs/windows/START-HERE-zh.md) 和 [macOS 安装与卸载](https://github.com/Yeeeee0-0/just-audio-plugin-bundle/blob/main/INSTALLING.md)。
Full steps: [Windows](https://github.com/Yeeeee0-0/just-audio-plugin-bundle/blob/main/docs/windows/START-HERE-zh.md) · [macOS](https://github.com/Yeeeee0-0/just-audio-plugin-bundle/blob/main/INSTALLING.md).

## 已知限制 / Known limits

- Windows 安装器和插件都未签名。<br>Windows Setup and plugins are unsigned.
- macOS 只提供 Apple silicon 版本。PKG 未签名、未公证，插件带开发用 ad-hoc 签名。<br>macOS is Apple silicon only. The PKG is unsigned and not notarized; plugins carry development ad-hoc signatures.
- 完整的 DAW 兼容性覆盖尚未验证，不保证所有宿主都兼容。<br>Full DAW compatibility coverage has not been verified; compatibility with every host is not guaranteed.
