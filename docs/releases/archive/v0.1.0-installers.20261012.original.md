# JUST 0.1.0 — Windows UI fix & macOS arm64 / 双平台安装包

## 下载 / Downloads

插件版本均为 **0.1.0**。推荐下载本页附件：
- Windows x64：`JUST-0.1.0-Windows-x64-preview-UI-fix-setup.exe`（最新 UI 修复预览包）。
- macOS Apple Silicon arm64：`JUST-Audio-Plugin-Bundle-0.1.0-macOS-arm64-b99abd3-selectable-unsigned.pkg`（已发布原包，字节未变）。
- 两端各含十款 VST3：EQ、Reverb、Delay、Tremolo、Compressor、Limiter、Gate、Flanger、Wider、Distortion。默认全选，可分别取消选择。

Both installers keep plugin version **0.1.0**. The Windows asset is the latest unsigned UI-fix preview; the macOS asset is the unchanged original Apple Silicon package. Both include the ten effects listed above, selected by default.

## 安装与卸载 / Install and uninstall

先保存工程并正常关闭使用 JUST 的音频宿主。Windows 使用 x64 VST3 目录（默认 Common Files/VST3）；保留安装报告和 ProgramData/ JUST 事务备份，使用该事务生成的卸载器恢复旧插件或移除首次安装项。macOS 安装到当前用户的 ~/Library/Audio/Plug-Ins/VST3；移除时仅移走该目录内对应 JUST 插件。勿删除宿主配置、许可证或个人工程。

Save projects and close hosts using JUST before installation. Windows provides a transaction-bound uninstaller and retains its backup. macOS installs to the current user's VST3 directory; remove only the corresponding JUST bundles when uninstalling.

## 本次变化与验证 / Changes and verification

Windows：更新批准的安装器图标和欢迎/完成页；修复模块下拉菜单瞬间关闭、选择回退及按钮重绘闪烁。DSP、参数与身份兼容契约、33ms 刷新和已核对的安装卸载逻辑保持原状态。

十款最终 x64 DLL 构建及有限范围原生 UI 检查通过；REAPER 7.41 定向八项通过（Flanger 六项、Delay 停止/播放两项）。新安装器展示、十项默认选择、隔离模拟安装、文件占用拒绝及卸载内容/目录恢复通过。沿用未改变逻辑的先前 51 项安装/40 项卸载证据，没有重跑全矩阵。新包物理 Cancel 按钮未重测；占用失败窗口经正常 WM_CLOSE 退出。卸载元数据并非全部恢复一致。

The Windows release fixes menu/selection stability and button painting, with approved installer artwork. Verification is bounded: ten native UI checks, eight directed REAPER checks, and isolated installer cases. It does not guarantee every DAW, audible DSP behavior, or all metadata restoration.

macOS：冻结 arm64 载荷与 ad-hoc 签名校验、安装包结构及选择界面已核对；PKG GUI 检查停在安装前确认，未执行该 PKG 的实际安装/升级或安装后扫描。本次未重编或重封装 macOS 包。

The macOS package is unchanged; its installer GUI was checked through pre-install confirmation. Actual PKG installation/upgrade and post-install scanning were not executed.

## 架构、签名与源码 / Platform, signing and source

Windows 插件为 AMD64；NSIS 启动器可为 x86。Windows 包与插件未签名。macOS 仅 arm64，插件为 ad-hoc 开发签名，PKG 无签名、未公证；没有 Intel/Universal 包。macOS 11.0 是构建部署目标，并非该版本运行验证承诺。

Windows VST3 payloads are x64 and unsigned. macOS is arm64 only: ad-hoc plugin signatures, unsigned and unnotarized PKG. No Intel/universal binary is included.

Windows 对应本发布 tag 的源码；macOS 原公开源码保持 [v0.1.0](https://github.com/Yeeeee0-0/just-audio-plugin-bundle/tree/v0.1.0)，提交 `f2a710510415395e13e548400143604c455df8fe`。MIT 许可及第三方通知保持不变。旧发布历史和资产保留。详见仓库中英 README、docs/releases/0.1.0-installers-20261012.md、SHA256SUMS.txt 和 release-manifest.json。
