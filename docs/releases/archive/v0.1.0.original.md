# JUST 0.1.0 — macOS Apple Silicon

Ten native VST3 audio effects for macOS Apple silicon: EQ, Reverb, Delay, Tremolo, Compressor, Limiter, Gate, Flanger, Wider and Distortion. Project code and authorized artwork are MIT licensed.

## Downloads

- Recommended: the selectable `.pkg` installer. All ten plugins are selected by default; each can be selected independently. Installation is for the current user.
- Manual installation: `JUST-0.1.0-macOS-arm64-VST3.zip`.
- Reviewed source: `JUST-0.1.0-source.zip`, with a complete file manifest in `SOURCE-SNAPSHOT.json`.
- See `INSTALLATION-GUIDE.md`, `THIRD_PARTY_NOTICES.md`, `LICENSE.txt` and `SHA256SUMS.txt`.

## Verified scope

The package uses the original frozen 0.1.0 binaries. The clean public source rebuilt all ten arm64 Release targets and passed eight shared CLI contract tests plus 32 identity/resource audit regressions. Installer GUI checks passed for default-all, single/mixed selections, restoring all choices, current-user scope and the pre-install confirmation page; that check stopped before installation.

The installer SHA-256 is `c1359f53d5307ff994c4d8fd1e8930e0f8a5996c3140dc31a09fea69cc4f56cc`.

## Platform and signing limits

Only macOS arm64 binaries are included. The PKG is unsigned and not notarized; plugin bundles have ad-hoc development signatures. macOS 11.0 is the build deployment target, not a verified runtime claim. Intel/universal builds and Windows binaries are unverified. Windows porting work is not part of this stable release.
