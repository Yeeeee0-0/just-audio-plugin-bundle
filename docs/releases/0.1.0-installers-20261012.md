## Source and changes

The release tag records the final Windows source and installer resources. The final UI update stabilizes menus and selections, skips redundant control placement/text updates and buffers button painting. Approved installer icon and welcome/finish resources are included. The final UI patch preserves DSP, UID/parameter/state contracts, layout, the 33 ms refresh interval and established install/uninstall transaction logic.

The macOS package is byte-identical to the original `v0.1.0` asset, with source at [`f2a710510415395e13e548400143604c455df8fe`](https://github.com/Yeeeee0-0/just-audio-plugin-bundle/tree/f2a710510415395e13e548400143604c455df8fe). Its frozen snapshot provenance is `b99abd3be4ad89b21e3a0c3caf1f12904503f168`, which is not a public checkout ref. The two packages were not rebuilt together. The current source keeps the original macOS implementation. Project MIT and third-party notices remain unchanged.

## Verification boundary

- Windows: final ten-DLL Release build and architecture/version records; ten bounded native UI scopes; eight directed REAPER checks (six Flanger menu checks and Delay stopped/playing phases). These cover the reported menu/selection/button symptoms, not a new complete DSP/audio/DAW matrix.
- Installer: seven icon frames (16/24/32/48/64/128/256), actual welcome/finish pages and default ten-component selection checked. Three new-Setup cases covered simulated installation, occupied-file refusal and uninstall content restoration. Existing 51-installation/40-uninstallation evidence was reused for unchanged logic; the full matrix was not rerun for publication.
- Limits: physical Cancel was not retested for this Setup. Uninstall restored original contents and directories, but stable metadata did not all match. The occupied-file failure window closed normally via WM_CLOSE; that is not a physical Cancel-button result.
- macOS: previous ten independent choices, 14 CLI selection scenarios and native Installer selection/pre-install confirmation checks retained. The GUI check stopped before installation. No fresh live macOS install, rebuild or host/audio matrix was run for this publication.

This release includes no Intel macOS/Universal or Windows ARM64 plugin binaries. A macOS 11.0 deployment target is a build setting, not certification on that OS. Ad-hoc signing is not Developer ID signing; no notarization is claimed. Compatibility with every DAW, system or user project is not established.
