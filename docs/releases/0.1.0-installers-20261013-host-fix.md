本次仅更新 Windows 安装器。修复未选中的第三方链接目录误挡安装；使用同卷事务保留旧插件，使宿主运行本身不再阻止安全安装和撤销。当前产品为 **JUST 0.1.0 正式版**，Windows 包未签名，完整 DAW 兼容性与音频覆盖尚未验证。十个 DLL、151 项插件载荷、UI、DSP、参数与批准美术均未变。

保存工程后可保留宿主运行。若插件编辑窗口锁住文件，安装器会安全拒绝并保留原内容：关闭该插件编辑窗口后重试。安装完成后正常重新打开宿主或重新加载插件才能使用新副本；不保证所有 DAW 无条件热替换或音频无间断。保留安装报告及对应事务备份，使用该事务原卸载器撤销。

最终 EXE 的 **8 项定向检查**完成，包括取消、运行中安装、文件锁定拒绝、正常重开和卸载还原；另复用此前安装器的 7 项未受影响证据。两项无效恢复报告诊断在原生 PowerShell 克隆夹具中核对。实际还原保留 153 个原文件、71 个目录及对象身份；顶层目录修改时间有变化，原检查器误判记录保留并以原始内容/身份记录核清。没有重跑完整插件 DSP/UI 矩阵。旧 Release、附件和许可证保留。

This update changes only the Windows installer. Unselected third-party linked directories no longer falsely block installation. Same-volume transactions retain old bundles, allowing safe installation and undo while a host remains running when the files can be moved. The current product is the **JUST 0.1.0 release**; the Windows package is **unsigned**, and full DAW compatibility and audio coverage have not been verified. All ten DLLs, 151 payload files, UI, DSP, parameters and approved artwork are unchanged.

Save your project. If an open plugin editor locks the files, installation safely refuses and preserves the original content; close that editor and retry. Normally reopen the host or reload the plugin to use the installed copy. This does not promise universal DAW hot swapping or gap-free audio. Keep the report and transaction backup, and undo with that transaction's original uninstaller.

**Eight directed checks** passed on the final EXE, with seven unaffected earlier-installer cases reused. Two invalid recovery-report cases were checked in native PowerShell clone fixtures. Actual restoration preserved 153 original files, 71 directories and recorded identities; the scan-root modification time changed. The original observer false failure is retained and reconciled against raw content/identity records. No full DSP/UI matrix was rerun. Previous releases, assets and licensing are preserved.
