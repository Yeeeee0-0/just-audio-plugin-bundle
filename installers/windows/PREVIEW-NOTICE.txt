JUST 0.1.0 -- Windows x64 preview
Yee Huang

This installer and the VST3 plugins are unsigned. Windows may display an
unknown-publisher warning. Verify the published SHA256 before running.

Windows native automated build/test evidence is separate from real host
acceptance. These plugins have NOT been visually or audibly accepted in the
user's REAPER installation. Use a NEW test project and follow the acceptance
checklist. Do not replace a production project with a test project.

Choose any of the ten components. All ten are selected initially. Only
selected JUST bundles in the selected destination are replaced. Unselected
JUST plugins and other vendors' files are left unchanged.

Before replacing files, the installer validates every candidate file and
creates verified backups of selected existing bundles. An installation error
triggers rollback where the files still match the known transaction. Keep
backups until you have completed real host tests.

Close REAPER normally after saving your work. The installer refuses to run
while REAPER or its plugin host processes are running; it never kills them.

User presets, REAPER settings, licenses and projects are not read or changed.
No registry uninstall entry or Start menu shortcut is created. Successful
Setup records the exact transaction's JUST-uninstall.exe and report path.
Keep that entry, its adjacent transaction-binding.json and old backups in
their original directory. Run the recorded EXE in place to undo this transaction.

Uninstall / undo this installation undoes ALL plugins selected in this
transaction: first-time installations are removed; overwritten plugins are
restored to their verified original versions. The transaction backups remain.
The confirmation shows the original VST3 destination and selected identities.
Normal Cancel does not call Restore or change plugins/journal. Silent /S uses
the same binding and protection. /REPORT= selects an external log path outside
the VST3 destination and transaction directory.

The uninstall entry uses its embedded trusted engine. It refuses moved entries,
missing or inconsistent bindings and unknown target/backup changes, including
empty directories and type changes. These writable transaction checks prevent
accidental mis-binding; they are not an administrator-resistant signature.
Entry-generation failure is incomplete Setup even if plugins were copied.
Each Setup binds its own private engine report and invocation GUID; a shared
external report never chooses the uninstall transaction. Default public
reports use a unique GUID filename. Create/Finalize require journal INSTALLED.
Requested uninstall reports are not written until the exact context and
outside-target path are verified. Early errors use only independently safe
refusal evidence or actual error output. After successful restoration, repeat
use permits only the exact old state; later reinstallations are preserved.

The source repository's LICENSE and THIRD_PARTY_NOTICES.md remain applicable.
No paid services, software downloads or account credentials are required by
this installer.
