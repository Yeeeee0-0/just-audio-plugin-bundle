JUST Audio Plugin Bundle

Version 0.1.0 · Yee Huang

Ten VST3 effects in one installation: EQ, Reverb, Delay, Tremolo, Compressor, Limiter, Gate, Flanger, Fake Stereo and Distortion.

Apple Silicon (arm64) only. Requires macOS 11.0 or later and a compatible host running natively on Apple Silicon. Intel and Rosetta host support is not included.

All ten plugins are selected by default. On the Installation Type / Customize page, select the plugins you want to install. Clearing a checkbox keeps any already installed copy unchanged.

The selected plugins install for your current macOS user.

Please save your work and close all audio hosts before continuing.

This private installer is unsigned and not notarized. The included plugins retain their original ad-hoc signatures; these are not Apple Developer ID signatures. macOS security policy may block opening or loading them.
