Installation details

Product: JUST Audio Plugin Bundle 0.1.0
Vendor: Yee Huang
Format: VST3 · Apple Silicon arm64

Choose your plugins

The Installation Type / Customize page has ten independent checkboxes, all selected by default. Keep the plugins you want and clear the others. Clearing a checkbox skips that plugin; it does not uninstall or change an existing copy.

Location

Install for me only. Selected plugins use the standard current-user folder:
~/Library/Audio/Plug-Ins/VST3
The tilde (~) means your home folder. The destination is fixed to avoid duplicate installations.

Upgrading

Only selected JUST bundles at this location are replaced using macOS Installer. Bundle identity and version checks are enabled. Newer installed bundles are not downgraded. Close your audio hosts first, then reopen and rescan VST3 plugins after installation.

User presets in ~/Library/Application Support/JUST/Presets/v1/, host projects and other plugins are outside the package. Custom files manually stored inside the ten .vst3 bundles should be moved out before replacement. Copies installed at other locations are not moved or removed.

Compatibility and signing

macOS 11.0 is the binaries' build minimum; older macOS releases have not been runtime tested for this delivery. This package has no Developer ID signature or Apple notarization. If macOS blocks the package or plugins, request a Developer ID signed and notarized build. Keep macOS security protections enabled.
